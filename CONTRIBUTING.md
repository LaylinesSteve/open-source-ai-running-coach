# Contributing

Thanks for your interest in contributing.

## How to contribute

- **Bug reports and feature ideas** — Open an issue in the project repository.
- **Code changes** — Open a pull request. Keep changes focused and describe what you’re doing and why.

## Getting started

1. Fork the repo and clone it locally.
2. Follow the [README](README.md) to set up the app (env vars, Strava, Redis, etc.).
3. Create a branch, make your changes, and run `npm run lint`.
4. Open a PR against the default branch. We’ll review and may suggest edits.

## Code of conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). By participating, you agree to uphold it.
